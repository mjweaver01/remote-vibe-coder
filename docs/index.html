Claude Code, from anywhere.

A tiny local web server that wraps the real claude CLI in a PTY and renders it in your browser. Review diffs, commit, and ship — all from your phone, over a built-in ngrok tunnel.

Features

Everything you need to vibe remotely.

Built around the real claude CLI. No reimplementations, no shortcuts — just a clean browser surface over the tools you already use.

Real PTY terminal

The actual claude CLI — slash commands, autocomplete, permission prompts, cancellation. No fake reimplementation.

Cross-device handoff

Sessions live on the server, not the browser. Open the same URL from any device on your LAN and pick up exactly where you left off.

Mobile-first keybar

Gameboy-style controls for permission prompts: 1/2/3, arrows, Esc, Tab, Ctrl+C — everything you need without a keyboard.

Files, diffs & commits

Monaco-powered viewer with git diff vs HEAD. Stage, unstage, and commit straight from the browser — no terminal trip required.

Conversation history

Resume any past Claude session from ~/.claude/projects/, or --continue the last conversation in a folder.

Voice input

Native Web Speech API mic button on the keybar. No model downloads, no external services.

Built-in ngrok tunnel

Add --ngrok and you get a public HTTPS URL with a one-shot token — no separate install, no reverse proxy, no port forwarding.

URL-driven state

Every view lives in the URL. Reload, share, or paste a link into another device — you land in exactly the same place.

Install

Local network

npx rvc --root ~/Websites

Binds to 127.0.0.1. Add --host 0.0.0.0 to reach it from your phone on the same Wi-Fi.

Over the internet (built-in ngrok HTTPS tunnel)

npx rvc --root ~/Websites --ngrok

ngrok is bundled — no separate install. Just bring an authtoken from ngrok. The URL carries a one-shot token stored in sessionStorage.

From source

git clone git@github.com:mjweaver01/remote-vibe-coder.git
cd remote-vibe-coder
npm install
npm run build
node dist/cli.js --root ~/Websites

Trust model

The token is shown only on the TTY where the server starts. Anyone with it can run claude as you — treat it like an SSH key. For WAN access, use --ngrok, Tailscale, or an SSH tunnel.
